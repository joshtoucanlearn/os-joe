# FLM1 Pixel 5x7 — web adaptation

Original FLAME UI alphabet, approved 29 August 2026. Copied with Joshua’s instruction for OS_Joe.
The web font preserves each filled cell of the original bitmap glyphs as square outlines. Lowercase routes to the original uppercase glyphs. Curly quotation marks route to their straight equivalents; spaces and dash aliases are included.

Source: FLAME tools/ui/build_flm1_pixel_font.py
Source SHA-256: 3332b529423edd02d501be08017efce1ec41b913d8d799cb379521da6ed9d459

Rebuild with scripts/fonts/build-font.py using Python fonttools and brotli. The original FLAME files are unchanged.
